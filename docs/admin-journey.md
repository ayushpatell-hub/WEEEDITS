# WEEEDITS - Admin Journey

## 1. Login
1. Opens the separate Admin Portal
2. Logs in with admin account
3. Role is checked (only "admin" is allowed)
4. Lands on Admin Dashboard

## 2. Dashboard Overview
- Total requests, active projects, completed projects
- New requests waiting for review
- Total clients
- Recent chat messages

## 3. Request Management
1. Opens a new request
2. Reads details and files
3. Changes status to Review
4. Chats with the client (Discussion)
5. Sends a quote
6. After client approval: Approved > In Progress
7. Uploads the final video: Delivered
8. Closes the project: Completed

## 4. Client Management
- View all clients
- View client project history
- Block or unblock a client

## 5. Content Management (no code)
- Portfolio: add, edit, delete videos
- Services: edit title, description, icon
- Pricing: edit plans
- Creators: add, edit, delete team members
- Homepage: change showreel and stats

## 6. Analytics (simple)
- Requests per month
- Requests by type (Video Editing / Paid Promotion)
- Completed vs active projects
- New clients per month

## 7. Chat
- See all client conversations
- Reply in real time

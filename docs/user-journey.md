# WEEEDITS - Client Journey

## 1. Visitor (not logged in)
1. Opens Home page
2. Watches showreel and sees stats
3. Browses Services, Portfolio, Creators, Pricing
4. Clicks "Start a Project"
5. Goes to Register or Login (Email or Google)

## 2. New Client
1. Registers with Email or Google
2. Lands on Client Dashboard
3. Sees empty state: "No projects yet"
4. Clicks "New Request"

## 3. Request Flow
1. Chooses request type: Video Editing or Paid Promotion
2. Fills the form (title, description, budget, deadline, files or links)
3. Submits the request
4. Status becomes: Submitted

## 4. Project Status Flow
Submitted > Review > Discussion > Quote > Approved > In Progress > Delivered > Completed

## 5. Working With the Team
1. Client opens Chat inside the project
2. Talks one-to-one with the team in real time
3. Receives the quote and approves it
4. Tracks progress on the dashboard
5. Downloads the delivered video
6. Project is marked Completed

## 6. Returning Client
1. Logs in
2. Sees all projects and their status
3. Opens chat or creates a new request
